# Contributing to FileRecover Pro

Thank you for your interest! This is a portfolio prototype, but improvements are welcome.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-improvement`)
3. Make your changes
4. Commit with a clear message
5. Push and open a Pull Request

## Ideas for Improvement

- Add more file signatures (Office documents, databases, etc.)
- Implement a real disk-image reader (raw / E01 support)
- Better footer detection and size estimation for videos
- Thumbnail generation for video files
- Export recovery report (CSV / JSON)
- Dark / light theme toggle
- Multi-language UI

## Code Style

- Follow PEP 8
- Use type hints
- Keep UI and core logic separated

## Testing

Because this tool deals with potentially large binary files, prefer manual verification with known sample images and short video clips.
